# Brownie Bakers (ESTD 2021)

> **"Bringing Affordable Delights to Tamil Nadu"**

Official website for **Brownie Bakers**, an artisan bakery and dessert brand operating across **Bodinayakkanur (Bodi)**, **Chinnamanur**, **Cumbum**, and **Theni**.

---

## 🎂 Features & Menu Categories

- **Brownies & Pastries**: Karuppu Kavuni Brownie, Ragi Brownie, Dark Chocolate, Sizzling Brownies, Tres Leches Pastry, Korean Bun, Cheesecakes & Panna Cotta.
- **La Pasta Italiana**: Cheese Penne, Penne Arrabbiata, Red Sauce Pasta.
- **Fast Food & Pizzas**: Non-Veg & Veg Burgers, Regular / Medium / Large Artisanal Pizzas, Sandwiches, & Loaded Fries.
- **Cakes & Custom Theme Cakes**: Signature Cakes, Chocolate Truffles, Fresh Cream Cakes, Pinata Cakes, Bomb Cakes, Barbie Cakes, Car & Pull-Me-Up Theme Cakes.

## 🚀 Getting Started

### Installation

```bash
npm install
```

### Running Locally

```bash
npm start
```
Open [http://localhost:3000](http://localhost:3000) to view in browser.

### Production Build

```bash
npm run build
```
Builds optimized production assets to the `build/` directory.
